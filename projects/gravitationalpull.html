Gravitational Pull



Description:

An educational interactive website built with plain HTML, CSS, and JavaScript that visually demonstrates how the Moon's gravitational pull affects Earth's tidal waves. Users can toggle the Moon to observe wave fluctuations and the Sun to see its additional effect, providing a clear and engaging understanding of how both celestial bodies influence Earth's tides.


Features:

  • Clicking on certain elements trigger transitions on images like shinkingm fading, and sliding
  • Speech synthesis reads text aloud, adding immersion and responsive audio cues.
  • Hovering over buttons or elements triggers visual feedback
  • Responsive design for all screen sizes
